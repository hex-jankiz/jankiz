# 🤖 Jankiz — منصة أخبار البرمجة والذكاء الاصطناعي ومشاريع GitHub

منصة برمجية وتقنية متكاملة ومؤتمتة بالكامل عبر بوت تيليجرام، تجمع أحدث تطورات هندسة البرمجيات، الذكاء الاصطناعي، ومشاريع GitHub مفتوحة المصدر، وتحديثات منصات التواصل الاجتماعي، والأمن السيبراني، مع بث تلقائي دوري للمشتركين.

```text

تابع أحدث لغات البرمجة وأطر العمل والمكتبات والتحديثات التي تهم المطورين.

اكتشف النماذج الجديدة والأدوات الذكية والتطبيقات العملية والتطورات الحديثة.

تابع تحديثات TikTok وYouTube وInstagram وFacebook وWhatsApp وTelegram وغيرها، مع أخبار الميزات الجديدة والمشكلات والحلول الموثوقة.

🐙 مشاريع GitHub
اكتشف مشاريع مفتوحة المصدر حقيقية، وأدوات برمجية مفيدة، ومكتبات جديدة، ومشاريع تستحق التجربة والتعلم منها.

تعرّف على الأدوات التي تساعدك على كتابة الكود وتحسين الأداء وبناء التطبيقات.

تابع التحديثات الأمنية والتنبيهات المهمة والممارسات التي تساعد على حماية التطبيقات والأنظمة.

استفد من أمثلة برمجية مفيدة ومشاريع قابلة للتحقق وشروحات واضحة.

Jankiz | البرمجة والتقنية، في مكان واحد.
```

## 🌟 الأقسام الفعلية للمنصة

1. **💻 أخبار البرمجة والتكنولوجيا:**
   - يغطي: Python، JavaScript، TypeScript، Go، Rust، C++، أطر العمل، وقواعد البيانات.
   - المصادر: Hacker News API، Dev.to Engineering، سجلات التوثيق الرسمية.
2. **🤖 الذكاء الاصطناعي:**
   - يغطي: نماذج LLM الجديدة، أدوات المطورين، الأتمتة، والمكتبات مفتوحة الأوزان.
3. **🐙 مشاريع GitHub الحقيقية:**
   - يكتشف مستودعات نشطة ومشاريع مفتوحة المصدر حقيقية بروابط مباشرة وعدد النجوم وتاريخ التحديث الفعلي.
4. **📱 منصات التواصل الاجتماعي:**
   - متابعة تحديثات وأعطال: Telegram، WhatsApp، YouTube، TikTok، Instagram، Facebook، Discord، Reddit.
5. **🛠️ أدوات المطورين:**
   - استعراض أدوات سطر الأوامر (CLI)، أدوات فحص الكود (Linters)، وأدوات اختبار الـ API.
6. **📚 أكواد وشروحات عملية:**
   - أمثلة برمجية مختبرة وموثقة في التزامن، قواعد البيانات، الأمان، وهندسة البرمجيات.
7. **🔐 الأمن السيبراني:**
   - تنبيهات الثغرات، إرشادات OWASP، وتحديثات حماية الأنظمة.
8. **🔔 إدارة الاشتراكات التلقائية:**
   - إمكانية الاشتراك في كل تصنيف على حدة، مع بث تلقائي كل 30 دقيقة للمشتركين.

## 🛠️ البنية التقنية وقاعدة البيانات
- **اللغة:** Python 3.11+ مع `python-telegram-bot` v20.
- **قاعدة البيانات:** SQLite (`jankiz.db`) لتخزين المستخدمين، الاشتراكات، الأخبار، المشاريع، وسجل منع التكرار.
- **المشرف الذاتي (Supervisor):** سكربت `supervisor.py` لإعادة التشغيل الذاتي الفوري عند أي انقطاع بالشبكة لضمان عمل البوت 24/7 دون توقف.
- **نظام الأمان:** محدد معدل الطلبات (Rate Limiting) لمنع الـ Flood والـ Spam، مع حماية المدخلات من أخطاء الـ HTML.
